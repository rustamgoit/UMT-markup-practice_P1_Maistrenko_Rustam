# Flora

Adaptive landing page for a flower shop, created from the Flora Figma layout.

## Technologies

- Semantic HTML5
- Mobile-first CSS
- JavaScript for the mobile menu and sliders
- modern-normalize
- Animate.css
- Optimized WebP images
- SVG sprite

## Breakpoints

- Mobile: 375px
- Tablet: 768px
- Desktop: 1440px
